# MCS-51 后端

## 目标身份

MCS-51 的稳定入口如下：

| 项目 | 值 |
|---|---|
| 编译选项 | `-mmcs51` |
| 预定义宏 | `__SDCC_mcs51` |
| 汇编器 | `sdas8051` |
| 默认运行库 | `mcs51.lib` |
| 默认模型 | `--model-small` |
| 普通代码地址 | 16 位 |
| 通用指针 | 3 字节，包含地址空间标签 |

本分支增加 MCS-251 时保留 MCS-51 的目标名、对象布局、指针标签、调用约定和指令
输出。MCS-251 的 24 位平坦指针、`ECALL`/`ERET` 和 SPX 规则不能进入 MCS-51
对象。

## 最小程序

```c
#include <stdint.h>

__sfr __at (0x90) P1;

void main(void)
{
    for (;;)
        P1 ^= 0x01;
}
```

编译：

```sh
sdcc -mmcs51 --model-small -o firmware.ihx main.c
```

器件寄存器优先使用 `device/include/mcs51/` 中匹配芯片的头文件。自行声明 SFR 时，
地址必须来自目标芯片资料。

## 地址空间

经典 MCS-51 的多个空间可以具有相同数值地址，但由不同指令访问：

| 修饰符 | 典型范围 | 访问和用途 |
|---|---:|---|
| `__data` | `0x00`-`0x7f` | 直接寻址内部 RAM |
| `__idata` | `0x00`-`0xff` | `@R0`/`@R1` 间接内部 RAM |
| `__bit` | 位地址 | 单个位对象 |
| `__sfr` / `__sbit` | SFR/位地址 | 外设和 CPU 控制寄存器 |
| `__pdata` | 256 字节页 | `MOVX @Ri` 分页窗口 |
| `__xdata` | 最多 64 KiB | `MOVX @DPTR` 外部数据 |
| `__code` | 最多 64 KiB | 程序和只读常量 |

直接地址 `0x80`-`0xff` 通常选择 SFR，而 `__idata` 的同一数值范围通过间接寻址
选择上半部内部 RAM。二者不是同一存储。

## 指针表示

| 指针种类 | 大小 | 表示 |
|---|---:|---|
| `__data` / `__idata` near 指针 | 1 字节 | 内部数据地址 |
| `__pdata` 指针 | 1 字节 | 当前页偏移 |
| `__xdata` / `__far` 指针 | 2 字节 | 16 位外部地址 |
| `__code` 指针 | 2 字节 | 16 位代码地址 |
| 通用指针 | 3 字节 | 两字节地址加空间标签 |
| 普通函数指针 | 2 字节 | 非 banked 代码地址 |

显式空间指针更小、更快，但只能访问指定空间；通用指针可以携带空间信息，代价是
访问辅助代码和更大存储。把指针强制转换到错误空间不是地址数值转换，而是改变访问
指令，可能读取完全不同的硬件空间。

## 内存模型

| 选项 | 普通对象默认空间 | 典型用途 |
|---|---|---|
| `--model-small` | `__data` | 小程序、速度和尺寸优先 |
| `--model-medium` | `__pdata` | 一个分页 XRAM 窗口 |
| `--model-large` | `__xdata` | 大量外部数据 |
| `--model-huge` | `__xdata` | banked 函数和更大代码布局 |

模型不改变显式地址空间。small 模型仍可声明大型 `__xdata` 缓冲区，large 模型也
可把热点对象放进 `__data`。所有翻译单元和运行库必须使用兼容模型。

## 自动变量、overlay 和可重入

默认普通函数的参数和自动变量可位于静态 overlay 区，由链接器根据调用图复用。
递归、间接调用和中断重入应使用：

```c
unsigned int checksum(const __xdata unsigned char *p,
                      unsigned int n) __reentrant;
```

或全程序使用：

```sh
sdcc -mmcs51 --model-small --stack-auto main.c
```

`--stack-auto` 改变参数和局部变量 ABI，必须匹配运行库。`--xstack` 使用外部伪栈，
也不能与默认硬件栈约定随意混用。

## 中断和函数扩展

```c
void timer0_isr(void) __interrupt(1) __using(1)
{
    /* 中断号和 bank 必须与芯片手册一致。 */
}
```

- `__interrupt(n)` 生成中断入口和 `RETI`；
- `__using(n)` 指定寄存器 bank；
- `__critical` 管理临界区中断状态；
- `__reentrant` 选择可重入约定；
- `__naked` 禁止自动序言和结尾；
- `__at(address)` 选择绝对地址。

`__naked` 函数不会自动保存寄存器或返回，必须由实现者完整负责。

## 目标和链接选项

| 选项 | 说明 |
|---|---|
| `--acall-ajmp` | 在可证明同页时使用 `ACALL`/`AJMP` |
| `--no-ret-without-call` | 禁止把跳转优化为独立 `RET` |
| `--stack-size N` | 为栈预留空间 |
| `--iram-size N` | 描述内部 RAM 大小 |
| `--xram-loc N` / `--xram-size N` | 设置 XDATA |
| `--code-loc N` / `--code-size N` | 设置代码空间 |

链接器不知道每种 8051 兼容芯片的真实内存和外设布局。项目必须传入正确地址，并
检查 `.map` 和 `.mem`。

## 汇编互操作

C 外部符号通常带前导下划线，例如 `foo` 对应 `_foo`。汇编函数必须遵守当前模型的
参数、返回值、寄存器保存和栈约定。内联汇编若改变编译器未获知的寄存器或内存，
优化后可能出错。

## 非回归验证

本分支比较修改后编译器与 SDCC 4.6.0 基线的规范化汇编及 Intel HEX，并在 QEMU
MCS-51 上运行：

```sh
make -C build/src/mcs251 check-mcs51-qemu \
    QEMU_MCS51="$HOME/oss/qemu/builds/build-mcs51-family/qemu-system-mcs51"
```

若 MCS-51 固件在 QEMU 中失败，应先用基线编译器、汇编差异和 trace 判断是编译器
回归还是模拟器问题，不能因为 MCS-251 代码刚修改就预设根因。
