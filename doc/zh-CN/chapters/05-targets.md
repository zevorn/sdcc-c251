# 支持的处理器

本章概述英文手册中各处理器后端的边界。完整选项以当前 `sdcc --help` 和对应端口
源码为准。MCS-51 与 MCS-251 因为是本分支重点，在后续独立章节详细说明。

## MCS-51 派生目标

`mcs51` 面向经典 8051 兼容器件。`ds390`/`ds400` 面向带扩展地址和专用调用机制的
Dallas/Maxim 变体。虽然这些后端共享部分源码，目标文件、指针和调用约定并不相同。
选择芯片头文件不能代替选择正确后端。

## DS400

DS400 后端继承 DS390 的扩展能力并配合特定启动和 ROM 环境。应用必须遵守板级
内存图、网络引导和库布局。普通 MCS-51 对象不能因为指令相似就直接链接进 DS400
程序。

## Z80 相关后端

SDCC 支持 Z80、Z80N、Z180、SM83、TLCS-90、Rabbit、eZ80、R800 等相关架构。
它们在寄存器集、地址宽度、调用约定、I/O 指令和指令可用性上存在差异。常见选项
控制寄存器参数、栈清理、指令子集和代码模型。

Rabbit 与 eZ80 还提供扩展地址或 far 空间。函数指针、结构返回和跨 bank 调用必须
使用对应后端的 ABI；不要以“Z80 兼容”为由混合库。

## HC08 和 S08

HC08/S08 后端面向 Freescale/NXP 8 位控制器。两者共享许多实现，但指令和器件能力
不同。中断声明、直接页、栈和链接地址应依据具体芯片。编译器不会自动知道每个器件
的 RAM/Flash 大小。

## STM8

STM8 后端使用 STM8 指令集和独立 ABI。近/远函数、指针、栈和中断返回均受代码
布局影响。链接脚本参数必须匹配芯片 Flash、RAM、EEPROM 和向量表。

## F8

F8 后端面向 F8 架构，支持程度和库覆盖应以当前版本测试结果为准。新项目在选择前
应验证所需 C 特性、调试工具和器件支持。

## MOS6502 和 WDC 65C02

`mos6502` 与 `mos65c02` 后端针对 6502 系列。zero page 地址空间可显著改善代码，
但容量有限；显式 `__zp`/`__data` 对象和调用约定必须与运行库一致。65C02 增加的
指令不能用于普通 6502 目标。

## PIC14 和 PIC16

PIC 后端的维护状态、器件数据库和 non-free 头文件具有特殊限制。Microchip 派生
头文件可能要求只用于真实 Microchip 器件，因此与自由运行库分开。使用时必须显式
启用相应 non-free 路径并遵守厂商许可。

PIC 的 banked 数据、分页代码、配置字、中断和链接脚本与 MCS-51 完全不同。部分
标准特性和大整数支持可能不完整；在产品采用前应运行目标回归并检查生成汇编。

## 目标选择原则

选择后端时应同时确认：

1. CPU 指令集和模式；
2. 指针与地址空间；
3. 函数调用和中断 ABI；
4. 可用启动代码、运行库和器件头文件；
5. 链接器能表达的物理内存图；
6. 模拟器、调试器和烧录工具；
7. 当前回归测试覆盖。

“能生成 HEX”只证明工具链完成了链接，不证明目标、芯片或运行行为正确。
